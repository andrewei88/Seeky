# Rename ARYA to Seeky Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rename the entire project from ARYA to Seeky across directories, files, code, scripts, and documentation.

**Architecture:** XcodeGen-based project, so `project.yml` is the source of truth for Xcode config. Rename directories/files with `git mv`, bulk-replace code references, regenerate xcodeproj. The root git repo directory stays as-is (user can rename externally).

**Tech Stack:** Swift/iOS, XcodeGen, Python scripts, CoreML

**Naming convention:**
- Project/module: `Seeky` (PascalCase)
- App struct: `SeekyApp`
- ML model: `SeekyClassifier`
- Bundle ID: `com.seeky.objectlearning`
- Queue labels: `com.seeky.camera.*`
- Python files/vars: `seeky_*` (snake_case)
- Training data dir: `seeky_training`
- Export zip: `seeky_training_captures.zip`
